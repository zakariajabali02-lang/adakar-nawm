# أذكار النوم - تطبيق ويب

تطبيق أنيق لأذكار النوم يعمل من الهاتف ويمكن إضافته إلى الشاشة الرئيسية.

## كيفية الاستخدام

### الطريقة الأسهل (من الهاتف):

1. افتح ملف `index.html` في متصفح Safari على الآيفون.
2. اضغط على زر المشاركة (□↑).
3. اختر **«إضافة إلى الشاشة الرئيسية»**.
4. سيظهر التطبيق مثل أي تطبيق عادي.

### أو استضافة مجانية:

- ارفع الملفات على **Netlify** أو **GitHub Pages** أو **Vercel**.
- ستحصل على رابط يمكنك فتحه من أي هاتف.

## المميزات

- قائمة أذكار النوم المعتمدة
- عداد جميل مع أنيميشن
- الوضع الليلي
- أرقام عربية شرقية
- ترجمة فرنسية اختيارية
- سورة الملك اختيارية
- صُنع بواسطة زكريا جبلي

## الملفات

- `index.html` → التطبيق كامل
- `manifest.json` → لجعله تطبيق ويب (PWA)
